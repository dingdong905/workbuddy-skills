# 教学方法论手册

教学循环（第 4-6 步）的操作细节。核心原则：学习发生在预测错误的时刻和复述卡壳的地方，教学设计要主动制造这两个时刻。

## 一、预测-验证循环（核心引擎）

**原理**：生成效应——先主动生成答案再看正确答案，记忆深度远超被动阅读；预测错误时大脑对差异最敏感。

**操作步骤**：

1. 展示实验命令 + 一句意图说明（「这条命令会展示 X」）
2. 提问：「先预测：输出会是什么 / 会发生什么现象？」
3. 等用户给出预测。用户说「不知道」时回应：「猜一个，错也没关系——错了才是学习开始的地方」。仍拒绝 → 让用户二选一（给两个选项）。
4. 执行实验，取回真实输出
5. 对照：
   - 预测正确 → 追问一层：「为什么是这样？机制上谁做的这件事？」防止碰巧猜对
   - 预测错误 → 黄金时刻：「你预测 X，实际是 Y。你觉得差异从哪来？」先让用户自己解释，再讲机制
6. 记录该章预测正确率（用于跳级/降级判断）

**禁止**：未经预测直接执行并讲解——那只是演示，不是教学。

## 二、苏格拉底提问（检验环节）

**原理**：不直接给答案，用问题引导用户自己推导出答案。

**问题梯度**（由浅入深五层）：

1. 现象层：「刚才输出里的 X 是什么意思？」
2. 机制层：「是谁、在什么时机做了这件事？」
3. 原理层：「为什么要设计成这样？换个设计会出什么问题？」
4. 边界层：「如果 X 条件不满足 / 规模放大 10 倍 / 某组件挂掉，会发生什么？」
5. 迁移层：「这个机制背后的思想，还出现在哪些你已经知道的地方？」「用同样的原理，解释/解决一个新场景的问题。」

**模板句式**：

- 「如果删掉/禁用 X，Y 还能工作吗？为什么？」
- 「X 和 Y 看起来都在做 Z，它们的分工边界在哪？」
- 「这个设计在什么情况下会变成瓶颈？」
- 「剥掉具体实现，这个机制的本质思想用一句话说是什么？」
- 「你在别处见过同样的思想吗？它在那里解决的是同一个问题吗？」

**纪律**：每章检验 2-3 问，其中至少 1 问是迁移层；**出题前先写好 2-3 个预期误解**（该知识点上最常见的错误答案/混淆是什么），用户答错时对照误解定位根因——是概念混淆还是缺前置，不同根因走不同补救；用户答不上来不直接给答案，先给一个提示性实验或降一层问题；**同一要点连续两轮未过 → 降级为先示范再练**（worked example 干预：给完整范例带讲解，再让用户重做变式），禁止无反馈硬练——无反馈的反复检索可能产生负效应（Fiechter & Benjamin 2018）；讲解后仍卡 → 标记该点为卡点。

## 三、费曼复述门禁

**原理**：能教给别人 = 真正学会。「我觉得懂了」是最大的学习错觉，复述会暴露所有幻觉。

**操作步骤**：

1. 每章结束：「用你自己的话，把本章机制讲给一个没接触过的同事听。可以画图。」
2. 听复述时记录：逻辑断点、因果错误、跳过的关键环节
3. 通过标准（三条全满足）：
   - 因果链完整无漏洞（A 导致 B 因为 C）
   - 能回答 2 个即兴追问
   - 核心组件关系能画出/说对
4. 不通过：指出具体漏洞（「你在 X 到 Y 之间跳了一步，这一步是谁做的？」）→ 补一个针对性实验验证该环节 → 重新复述
5. 第二次仍不通过 → 该章拆成两个半章重教，说明用户被前置概念卡住了

**纪律**：AI 不代写复述、不替用户总结「你想说的其实是……」；用户主动要求跳过时标记该章「未验证」并继续，但下一章检验题要覆盖上一章未验证要点。

## 四、概念讲解规范

- 一章一个心智模型 + 一张图 + 一个现实类比
- 现实类比优先从用户已知领域取（从用户背景信息判断其熟悉的领域，用该领域的现象做类比；不确定时先问「你熟悉 X 吗」）
- 新名词单次引入 ≤3 个，每个必须带一句类比，否则拆到下一章
- 先全局后局部：先给组件关系全景图，再逐个深入
- 讲结论时同步给「重建路径」：指出从哪些更基础的机制可以把这个结论重新推出来——结论可以忘，推导路径长存，这是理解性记忆的教学侧入口
- 图用可视化输出（架构图、序列图、流程图），文字讲因果，图讲结构
- 讲解 ≤1500 字，超了拆两次交互（遵守 concise-output）

## 五、实验设计规范

每个实验必须满足三条：

1. **可观察**：有明确输出可与预测对照（命令输出、路由表、抓包、事件流）
2. **最小**：一次只验证一个概念，禁止复合实验（教学初期）
3. **安全**：非破坏性查看命令优先；涉及 delete/重启/改状态 → 标注风险等级 + 必须先获用户确认

**实验失败的用法**：环境故障、命令报错不是教学事故，是免费教材——带着用户走一遍：读报错 → 定位 → 验证假设。排错过程本身就是该领域最需要练的能力。

**练习模式（无动手环境主题的平替）**：理论、语言、人文类主题没有实验环境，实验环节替换为：练习题（先预测答案再对照标准答案）、造句/应用题（用刚学的概念解释一个新现象）、推演题（给定条件推结果）。设计要求与实验一致：可观察（有明确答案可对照）、最小（一次练一个概念）、有预测环节。

**环境不可用降级**：明确告知「无法实验」，给权威文档对应章节链接，改为推演教学（图 + 因果链），并在学习状态里标记「本章未实验验证」，环境恢复后补实验。

## 六、跳级与降级

| 信号 | 判定 | 动作 |
|---|---|---|
| 单章预测正确率 ≥80% 且检验全对 | 掌握 | 建议跳过本章剩余实验，直接费曼复述通过 |
| 连续 2 章 ≥80% | 整体偏易 | 建议跳 1-2 章或加速，把省下时间投给深学层 |
| 单章预测正确率 ≤40% | 前置缺失 | 停下，回滚补前置概念（从主题包找依赖章或现教） |
| 费曼复述两次不过 | 理解断裂 | 拆章重教 + 标记卡点 |

跳级/降级先建议、用户确认后执行；用户始终有权推翻（用户是学习的主人，skill 是教练不是狱卒）。

## 七、间隔复习（FSRS 简化规则版，理解性记忆导向）

**理解性记忆原则**：复习的是因果链与推导路径，不是答案原文。能重新推导的知识永远忘不干净——细节丢了可以重建；只会背原文的，场景一变就失效。

- 每章通过后生成 3-5 张复习卡，格式：

```
[第N章] Q: <理解型问题>
A: <因果链要点——评判基准而非背诵标准，≤3行>
I: <当前间隔天数>
```

- **出题规范——只出理解型题，禁止背诵题**：
  - ✅ 机制推导：「为什么裸金属上 LoadBalancer 会 pending？」（要求因果链）
  - ✅ 预测题：「停掉 leader 节点的 speaker，客户端会怎样？为什么？」（给条件推结果）
  - ✅ 反向题：「客户端 ARP 表里 VIP 换了新 MAC，说明刚发生了什么？」（给现象反推原因）
  - ✅ 对比题：「BGP failover 为什么比 L2 快？」（差异背后的原理）
  - ❌ 定义题（「MetalLB 是什么」）、列举题（「列出三个 CRD」）、数值题（参数默认值）
  - 细节类内容（参数名、命令 flag、版本号）不进复习卡——那是会用层，随用随查；卡片只放心智模型与因果链
- **评判标准**：答对 = 因果链完整、能推导出结论。允许用户用自己的话、任意顺序、从不同入口推导，不要求与卡片答案字面一致；回答「像正确答案但不通」（背下来的壳）→ 追问一个「为什么」当场识别
- 卡片双重落盘：主题包「复习卡」区块 + 工作区记忆（当日日志）
- **间隔调度规则**（FSRS 思想的规则简化版，KDD 2022，依据见 research-basis.md）：
  - 答对且流畅 → 当前间隔 ×2.5（1 → 3 → 7 → 17 → 42 天…）
  - 答对但卡壳 → 间隔不变，下轮重抽
  - 答错 → 间隔重置为 1 天，重新爬
  - 三连对且间隔 ≥30 天 → 该卡毕业（移出抽查池）
- **抽查必须跨章混抽**（交错练习，辨别学习）：从不同章、不同主题的到期卡中随机抽，不按章顺序——混抽迫使先判断「这是哪类问题、该用哪个模型」再作答，这正是排障与迁移的核心能力
- 抽查时机：新学习会话开头，抽 2 张到期卡；答错 → 重置间隔，下轮优先
- 技能型复习以「再做一次」代替「再答一遍」（写过的字隔周再写、学过的定式在实战中识别），复习任务同样混排
- 主题全部学完 → 生成一份「该主题 10 分钟速查手册」文件交付用户（心智模型图 + 排障清单 + 复习卡全集）

## 八、举一反三（迁移训练）

**原理**：真正理解的标志是迁移——把一个领域学到的原理用到没见过的场景。只会在原场景复现 = 背诵，能在新场景应用 = 理解。这也是「学以致用、不局限技术」的落点：学的是思想，不只是知识点。

**操作步骤**（每章检验后、进入下一章前）：

1. **先问后给**：「这个机制背后的思想，还出现在你已经知道的哪些地方？」——必须先让用户自己迁移，答案不限于本领域（历史、生活、其他行业均可）
2. **用户答出** → 追问一句「它在那里解决的是同一个本质问题吗？」验证是真迁移还是表面相似
3. **用户答不出** → 给 2-3 个跨领域例子（覆盖不同距离：近迁移=同领域、远迁移=跨行业），每个一句话讲清对应关系，然后让用户再举一个
4. **模式提炼**：一句话总结本章可迁移模式（格式：「本章本质是 X 思想：<一句话描述>」），写入主题包对应章节，主题学完后这些模式构成用户的「模式库」

**迁移题设计模板**：

- 换场景：「同样的机制，放到 X 场景下成立吗？」
- 反向应用：「如果让你在新系统里解决同样问题，会怎么借鉴这个设计？」
- 找同类：「A 和 B 表面无关，本质是同一个思想的两个实例——说出这个思想」
- 跨领域：「用这个原理解释一个非技术现象」

**纪律**：

- 每章至少 1 个迁移题，启发式优先——用户自己举出的例子永远比 AI 给的更有价值
- AI 补例子时必须跨距离（至少 1 个远迁移），防止只在同领域打转
- 复习卡中按 1:5 比例配置迁移卡（「X 思想还出现在哪？」），复习时优先抽查
- 禁止把迁移做成知识灌输（一次甩 10 个例子）——一次 2-3 个，重点是让用户学会「找同类」这个动作本身

## 九、技能型教学（刻意练习）

**原理**：技能 = 认知框架（可讲清）+ 肌肉/模式记忆（只能靠正确重复获得）。费曼复述对技能型无效——讲得清 ≠ 做得出。刻意练习三要素：**分块、即时反馈、舒适区边缘**。

**教学循环**：

1. **示范**：给高质量示范（真迹范本、大师演绎、标准动作分解图/视频），先整体看，不讲解
2. **拆解要点 + 预测**：示范后先问「你觉得做好这件事的关键 1-3 个点是什么？」——让用户先预测要点，再公布拆解
3. **模仿练习**：用户动手做，从分块开始，宁慢勿快
4. **对照差距**：用户预测的要点 vs 实际卡住的地方——差距即教学点
5. **纠正**：针对差距给具体纠正（一个练习只纠正一个点，禁止一次纠五个）
6. **重复**：舒适区边缘重复，直到该分块稳定，再进下一块

**分块方法**：把大技能拆成可独立练的小块（书法：单字结构 → 偏旁 → 行气 → 章法；琴：单手 → 慢速合手 → 原速；外语：音 → 词块 → 句 → 对话）。每块有明确「稳定标准」才进下一块。

**分块 → 交错两阶段**：分块期（新手）：按块顺序练，每块到「基本稳定」即可，不求自动化；交错期（辨别期）：把多个已稳定的分块**混合随机练**——交错练习的长期保持大幅优于纯分块（数学一周后 63% vs 20%，Rohrer & Taylor 2007），且迫使「先判断这是什么类型的问题、该用哪个方法」，正是实战排障的核心能力。切换时机：各分块能稳定做对但尚未自动化时。**提前告知用户：交错期即时表现会变差，这是合意困难，属正常**——约 80% 的学习者会误以为块状练习更有效，感觉不可靠，结果可靠。

**即时反馈的方式**：AI 能做——用户上传作品照片/棋盘截图/练习录音转文字后的结构分析，给文字图像层面的对照反馈；AI 不能做——实时听辨音色、触觉手感，此类明确说「需要线下老师或录像对照自查」，并提供自查清单（该动作的 3-5 个观察点）。

**练习记录规范**（每次练习逐条追加到主题包）：

```
[日期] 练习内容：<分块名>
对照差距：<预测要点 vs 实际做到的>
纠正点：<本次修正的一个点>
下次：<下一个分块/重复计划>
```

练习记录是调整计划的依据：同一差距连续出现 3 次 → 说明该分块拆得还不够小，回炉再拆。

**常见坑（要主动拦）**：

- 舒适区陷阱：只练喜欢/擅长的分块 → 按「最弱分块优先」排计划
- 练量不练质：带着错误动作重复 = 巩固错误 → 每次练习必须有对照环节
- 贪快：速度是稳定后的自然结果，强制提速毁动作

## 十、修养型教学（品味校准）

**原理**：无标准答案的领域（鉴赏、审美、棋感、品鉴），能力 = 分辨力。不靠背诵结论，靠大量高质量样本输入 + 对比讨论形成内隐判断。**范本质量决定校准上限**。

**教学循环**：

1. **范本接触**：成对呈现样本（公认好 vs 公认差，或同作者早晚期），先感受，不急着说
2. **对比讨论**：问「这两个给你的感受差在哪？你觉得是什么造成的？」
3. **形成判断**：要求「判断 + 理由」结构输出：「我认为 A 更好，因为 X、Y」。禁止「都挺好」——不表态就无校准
4. **输出观点**：让用户独立评一个新样本，说给外行听
5. **被挑战**：AI 扮反方：「有人说 B 更好，因为 Z，你怎么回应？」——检验理由是否站得住

**范本纪律**：必须用真迹、真声、原始版本（字帖影印、大师原始录音、名家实战棋谱）；**AI 生成内容禁止作为范本**（AI 的字、AI 合成的演奏不能做品味锚点）。AI 对艺术样本的评价本身也不是权威——AI 的角色是促进用户思考和对比，不是输出标准答案。

**盲测**：隔期（复习节奏）给盲选样本让用户判好坏并说理由——盲测稳定命中说明校准成立，这是修养型的「门禁通过」标准。

**与知识/技能型的配合**：修养型主题通常有知识型底层（乐理、书论、棋理）——先用知识型循环建认知框架，再用本循环校准感受，两层交替。
