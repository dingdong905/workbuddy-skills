# 值不值得学：五维判断框架（抽象层）

本文件只放通用判断逻辑，不含任何具体主题的例子、评分理由、学习内容——那些一律写入 `topics/<topic>.md` 主题包。

## 为什么需要闸门

学习资源无限，时间有限。最大的浪费不是学不会，而是把时间花在不值得的地方。「全都值得学」等于没筛。每个新主题进入教学前，先用本框架打分，产出三层投入结论；不值得学的，必须明确告诉用户。

## 五个维度与评分锚点（各 1-5 分）

### 1. 目标相关性——「解决我当前或可预见的问题吗」

学以致用是第一标准。判断对象是「这个知识能否在用户的实际场景（工作、项目、生活目标）中产生真实作用」。

| 分 | 锚点 |
|---|---|
| 5 | 当前痛点，学完短期内就能用上 |
| 4 | 日常/周期性接触的场景 |
| 3 | 可预见 3-6 个月内会用到 |
| 2 | 间接相关（拓宽视野类） |
| 1 | 与用户任何实际目标无交集 |

### 2. 知识半衰期——「是原理还是工具，多久过时」

| 分 | 锚点 |
|---|---|
| 5 | 底层原理/第一性原理，十年以上不过时 |
| 4 | 原理为主，少量实现细节 |
| 3 | 框架/体系层，预计 3-5 年主流 |
| 2 | 生态活跃但竞争者多，随时可能被替代 |
| 1 | 特定工具的语法/参数/操作细节，版本一变就作废 |

判别法：对该主题核心内容问一句「十年后还有效吗」。

### 3. 学习杠杆——「学完能撬动多少别的知识」

| 分 | 锚点 |
|---|---|
| 5 | 多个领域/主题共同依赖的地基概念，学一门通一片 |
| 4 | 一个体系内多处复用 |
| 3 | 单一主题内复用 |
| 2 | 与已有知识弱关联 |
| 1 | 孤岛知识，学完只在这一个点有用 |

### 4. 认知密度——「核心心智模型占内容的比例」

| 分 | 锚点 |
|---|---|
| 5 | 心智模型占比 >70%，一两个模型讲清主体 |
| 4 | 模型清晰，但淹没在细节里，需主动提炼 |
| 3 | 模型与细节约五五开 |
| 2 | 大量碎片细节，模型稀薄 |
| 1 | 几乎全是细节罗列 |

判别法：问「这个主题能不能用一张图 + 三句话讲给外行听」。能 → 密度高。

### 5. 复用频率——「实际会用到的概率」

| 分 | 锚点 |
|---|---|
| 5 | 日常高频（每天/每周） |
| 4 | 所辖场景长期存在、周期性接触 |
| 3 | 每月级 |
| 2 | 一年几次 |
| 1 | 一次性场景 |

## 分数 → 投入决策映射

| 总分（满分 25） | 决策 |
|---|---|
| ≥18 且无单项 ≤2 | 开正式主题包，完整教学循环 |
| 12-17，或 ≥18 但有单项 ≤2 | 压缩版：只过深学层，1-2 章速览，不开完整路径 |
| <12 | **不建议投入**：30 分钟速览（是什么/解决什么/什么时候需要）后明确劝退 |

单项 ≤2 一票否决完整教学：即使其他四维全 5 分，存在致命短板（如一辈子只用一次）时，学深没有任何意义，压到会用层以下。

## 「不值得学」的告知义务（硬规则）

- 评分落入「不建议投入」档 → 开门见山告诉用户：**这个主题对你不值得投入**。
- 必须附带：每维扣分理由（一句话/维）+ 一个 ≤30 分钟的速览选项（满足好奇心即可打住）。
- 禁止和稀泥表述：「也可以学学看」「以后再说」「看你兴趣」。要么给投入建议，要么给劝退理由，态度必须明确。
- 禁止迎合：用户兴致高不是加分项，五维里没有「热情」这一维。热情可以在投入后转化为动力，但不能作为抬高分数的理由。
- 用户决定要学 → 建议表达一次即止，转入全力教学模式：不再重提、不留劝退标记、不设区别对待。用户要学就教，教好为止。

## 三层投入定义

### 深学层（建立心智模型）

- 目标：能徒手画出结构图、能向同事/朋友讲清机制因果、能从第一性原理推导行为
- 特征：原理、架构、运作机制、失败模式——**为什么**层面的知识
- 检验标准：费曼复述通过 + 能预测未做过的实验/练习的结果

### 会用层（掌握操作能力）

- 目标：会动手做、会常规配置、会按流程排错，细节忘了知道去哪查
- 特征：操作步骤、参数、流程、排查路径——**怎么做**层面的知识
- 检验标准：能独立完成一次真实任务

### 略过层（标记不学）

- 目标：知道存在即可，用到时再查
- 特征：内部实现细节、版本差异、冷门参数、专家专项知识——**只有专职人员需要**的知识
- 处理方式：被问到时一句话定性 + 给权威查询入口，禁止展开

## 判断输出格式（写入主题包）

```
## <主题> 五维评分（日期）
| 维度 | 分 | 一句理由 |
（五维表，具体理由写这里，不写进框架文件）
总分 X/25 → 决策：正式教学 / 压缩速览 / 不建议投入

深学层：…（清单）
会用层：…（清单）
略过层：…（清单）
```

评分结果存入主题包，同主题不重复判断；主题发生重大变化（替代品出现、用户目标变化）时可重评。

## 反模式（禁止）

- **不筛就学**：跳过闸门直接开讲，是本 skill 要消灭的头号浪费
- **会用层升格深学层**：最常见的隐性浪费——把操作细节当原理教
- **以流行度提分**：热度、口碑不在五维内；流行的东西半衰期可能更短
- **以用户热情提分**：见「告知义务」——迎合是判断力的失职
- **沉没成本绑架**：已学一半但评分下降（被替代/目标消失）→ 按当前分数处置，果断止损
- **评估瘫痪**：闸门最多花 5 分钟，打分是判断力练习而非研究任务
- **按学习风格适配**：「视觉型/听觉型学习者」无实证支持（Pashler et al. 2008，90%+ 教师仍误信）；个性化只走有证据的两条路——已知领域类比、诊断定起点
- **劝退不给替代**：说「不值得」的同时必须给速览选项和「什么条件下值得重评」
