# 报告骨架（十节模板）

报告标题：`公司名（代码）深度分析：一句话主题`

开头固定三行：**Recency Statement**（最新报告期与检查截止日）、**Reporting basis**（口径、币种、单位）、**Data Quality Note**（一手来源、未审计标注、未取得的数据）。

## 一、Verdict / Summary（结论先行）

- 一句话结论：公司定性 + 核心矛盾 + 当前估值处于什么位置
- 信心等级（高/中/高）及原因（财务事实信心 vs 估值信心分开说）
- 当前估值快照：市值、TTM PE（归母/扣非）、PB、表面 P/FCF 及其失真因素
- 核心观察点：未来 1-2 个报告期看什么来证实/证伪

## 二、商业模式与产业链

1. 产业链全景：上游（原料、单一来源风险）→ 制造（核心能力与利润池）→ 渠道（模式、增速、毛利率、客户集中度）→ 终端（付费逻辑、政策敏感点）
2. 核心壁垒及强弱：逐项列，并注明"并非永久"的部分（专利到期、批文、渠道变迁）
3. 量价背离检查：销量/收入/库存三者增速对照，背离必须显式追因
4. 政策与新品：集采中标价与采购期、基药/医保目录变化的真实弹性（入选≠放量）

## 三、现金流

1. 五年现金转化表：收入 / 归母净利润 / CFO / 资本开支 / 简化 FCF / CFO÷净利润 / FCF÷净利润；标出 CAGR 与断点
2. 当期异常归因：营运资本明细（应收增减、应付增减、应计负债变动）、并表口径影响——结论是"经营拐点"还是"时间错配"
3. 应收压力检查：应收增速 vs 收入增速、坏账准备率、可能原因与验证条件

## 四、盈利质量

1. 非经常损益占比（近两期）
2. 销售费用：总额、费率、产品推广费明细、应计负债余额与结算节奏——高费用行业必查服务真实性
3. 研发：费率、资本化率
4. 资产负债表与资本配置：经济性净现金认定（存款/理财逐项）、偿债风险、分红与股息率（注明依赖规范化 FCF 而非单期利润）

## 五、重大并购（如有）

对价、持股比例、商誉及占对价比例、业绩承诺有无；并表贡献（收入/利润/CFO 分列）；跟踪指标清单（收入增速、毛利率、CFO/净利润、核心产品放量证据）。

## 六、治理与会计

审计意见与任期；资金占用/担保/诉讼；控股股东持股与质押（占其持股比、占总股本比，趋势）；关联交易要点。

## 七、估值

1. 当前倍数表（含解读列）：TTM 归母/扣非 PE、PB、股息率、经济性 EV、P/FCF（注明失真）
2. 反向 DCF：当前 EV 隐含的前五年 FCF 增速，对照历史增速，说明"市场已计入什么"
3. 三情景 PE 估值表：情景/概率/EPS/合理 PE/每股价值/关键假设；概率加权价值 vs 现价的空间
4. DCF 交叉验证：给区间不给单点，说明区间宽的原因（净现金认定、终值敏感性）
5. 明确基准锚：说明选 PE 中枢还是 DCF 单点作基准，为什么

## 八、行业相对评分卡

维度（可调）：商业模式与护城河 / 成长质量 / 盈利能力与资本回报 / 现金流与盈利质量 / 资产负债表 / 治理与会计 / 估值。各配权重、得分/10、核心依据；综合加权分。**Gates 行**：否决门槛（持续亏损、审计非标、偿债压力、高比例质押等）是否触发。

## 九、关键风险与证伪触发器

1. 主要风险（编号列出，按杀伤力排序）
2. Thesis invalidation triggers：
   - 上修触发（量化条件，如 CFO/扣非净利润 ≥1 连续两期）
   - 下修/退出触发（量化条件，如全年 CFO/净利润 <0.8、应收增速 >30% 且收入个位数）
3. 下一批必须跟踪的数据（具体到科目与公告）

## 十、数据质量与来源

- 数据校验说明：口径、TTM 构造方法、简化 FCF 定义、脚本检查结果
- 一手来源清单：法定披露 PDF 链接 + 页码
- 分析推断 vs 管理层确认的边界声明
- 免责声明收尾

## 交付规范

报告全文写 `.md` 文件交付；对话只给 ≤300 字摘要（核心判断 + 估值中枢 + 首要证伪条件）。
