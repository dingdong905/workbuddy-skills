# 上市公司深度研究（stock-deep-research）

产出另一名分析师可直接审计的个股深度报告。流程五步，缺一不可。

## 定位与分工

- 本 skill：研究流程、数据规范、报告骨架
- **evidence-research**：一手来源检索与交叉验证（配合使用）
- **growth-swing-trading**：研究完成后转入交易判断与仓位节奏
- **wb-finance-skill**：行情与金融数据总入口
- 本 skill 只做研究，不给买卖指令

## 流程

### 第 1 步：数据采集（intake）

按 `references/data-schemas.md` 的 intake schema 落盘 JSON，硬性要求：

- 一手来源优先：法定披露（年报/半年报/季报/公告，上交所/深交所/巨潮）；行情数据标注接口与查询日期
- 每个数据点记录：metric / value / period / basis（合并或母公司）/ unit / source（含 PDF 页码）/ source_tier
- source_tier：1=法定披露，2=第一方 IR，3=独立二手分析，4=聚合器与行情接口
- 报告期、币种、单位、最新披露日期、是否经审计，全部显式记录
- **not_available 列表必须写**：拿不到的数据（管理层指引、客户明细、同日可比估值等）如实列出，不许静默跳过

### 第 2 步：勾稽校验

- TTM 构造：FY + 当年 H1 − 上年 H1，注明口径
- 三表交叉：CFO 与净利润的五年趋势、应收/存货增速 vs 收入增速、应计负债变动
- 口径一致：合并 vs 母公司、含 vs 不含少数股东权益
- 校验不通过的数字不得进入分析；发现背离（如销量降收入升、利润增现金流降）必须显式追因

### 第 3 步：基本面分析

按 `references/report-template.md` 的十节骨架展开。要点：

- **结论先行**：一句话定性 + 信心等级 + 当前估值快照 + 核心观察点
- 现金流章必须拆：长期现金转化（五年 CFO/净利润）→ 当期异常归因（营运资本、应计负债、并表口径）
- 盈利质量章必查：非经常损益占比、销售费用率与结算节奏、研发资本化率、审计意见与任期、控股股东质押
- 重大并购单独成章：对价、商誉占比、业绩承诺（如有）、并表贡献、跟踪指标

### 第 4 步：估值（多方法交叉）

按 `references/data-schemas.md` 的 valuation schema 落盘，至少三法并用：

1. 当前倍数：TTM PE（归母与扣非两口径）、PB、股息率、经济性 EV（超额现金单独认定并说明）
2. 反向 DCF：当前市值隐含的增长预期是多少——回答"市场已经计入了什么"
3. 三情景概率加权：Bear/Base/Bull 各配 EPS、合理 PE、关键假设
4. DCF 交叉验证：给出区间并说明为何宽（净现金认定、终值敏感性）

**估值给区间和概率加权中枢，不给单点目标价。**

### 第 5 步：证伪触发器（强制章节）

报告必须包含：

- 上修触发：量化条件（如"CFO/扣非净利润连续两期 ≥1"）
- 下修/退出触发：量化条件（如"应收增速 >30% 而收入个位数"）
- 下一批必须跟踪的数据清单（具体到报表科目与公告类型）

## 硬性纪律

- 区分事实 / 计算 / 推断 / 预测；推断显式标注"分析推断，非管理层确认"
- 每个财务数字带 source 与 period；价格与市值带 as-of 日期
- 未审计报告期显式标注（如 H1 报告未经审计）
- 报告收尾附一手来源清单（PDF 链接 + 页码）与数据校验说明
- 免责声明：研究分析，不构成个性化投资建议
- 报告写入文件交付，对话只给 ≤300 字摘要（遵守 concise-output）
